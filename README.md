## 📖 About

**Minimalist Developer Portfolio** is a lightweight, high-performance static portfolio website crafted with pure **HTML5**, **CSS3**, and modern **JavaScript**.

It is designed for web developers, software engineers, and designers who want a clean, zero-bloat platform to present their biography, showcase their projects, and receive messages through an interactive contact form with instant validation feedback.

---

## ✨ Features

- ⚡ **Zero Bloat & Instant Loading**: Built with native web technologies with zero dependencies and no build steps required.
- 📱 **Responsive Design**: Smooth CSS grid and flexbox layout adapting effortlessly from mobile devices to desktop viewports.
- 🎨 **Minimalist Aesthetic**: Clean typography, elegant color contrasts, and subtle hover interactions.
- 💼 **Project Showcase Grid**: Modular card layout showcasing featured applications, descriptions, and source links.
- ✉️ **Interactive Contact Form**: JavaScript-driven form handler providing real-time submission confirmation.
- 🧭 **Smooth In-Page Navigation**: Sticky header with smooth scrolling anchors between About, Projects, and Contact sections.

## 🚀 Quick Start

### Direct Launch

No compiler or package manager needed! Simply clone and open:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kecrwn/temptests.git
   cd temptests
   ```

2. **Open in your browser:**
   - Double click `index.html`, OR
   - Serve using any static HTTP server:
     ```bash
     # Using Python 3
     python3 -m http.server 8080

     # Or using Node.js npx
     npx serve .
     ```

3. Navigate to `http://localhost:8080` in your web browser.
